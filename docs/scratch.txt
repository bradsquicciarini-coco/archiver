message format:
```
  pilot_assignment_id  : pilot assignment id 
  device_id            : device id for this
  valid_start          : starting timestamp where both bags and video exists
  valid_end            : similar but the end
  valid_length_seconds : length of overlapping logs
  files                : list of files 
  n_files              : number of files
```
